Overview

What this program is.

The Software Development program is a three-year, 624-hour specialisation for students from Class 11 onwards, with no programming knowledge assumed. It progresses from computer and programming fundamentals to professional full-stack, cloud and software-engineering capability, with a one-hour exam after each of 36 monthly modules.

Intended learner

Class 11 onwards; no programming knowledge assumed.

How it is assessed

One 1-hour exam after each of the 36 monthly modules (theory plus practical where appropriate). Exam time is included in the 624 hours.

Earning potential

What can you earn in India?

Entry-level roles linked to Software Development typically pay ₹4–8 LPA in India, rising with experience to ₹25–50+ LPA at senior level. These are market estimates, not guarantees.

Freelance work is another route: indicative rates are ₹500–1,200 an hour with 0–2 years' experience, rising to ₹2,500–5,000+ after 5 years.

Questions

About this program.

Who can join this program?

Class 11 onwards; no programming knowledge assumed. The program is open to students from Class 11 onwards.

How many hours is the program, and how is it structured?

It is 624 hours over three years (36 months): 4 hours a week for 52 weeks a year, or 208 hours a year. Each monthly module ends with a one-hour exam, and exam time is counted inside the 624 hours.

Does the program guarantee a job or internship?

No. The curriculum aims at job readiness through skills, hands-on practice, a GitHub record and a portfolio, but it does not guarantee an internship, employment or salary.

Which external certifications does the roadmap include?

The roadmap lists six external certifications: Microsoft Certified: Azure Fundamentals (AZ-900); Oracle Certified Foundations Associate (Java); HackerRank Skills Certification (SQL / Problem Solving); Meta Front-End Developer Professional Certificate; Oracle Certified Professional, Java SE (OCPJP); AWS Certified Developer – Associate. They are awarded by the certifying organisations, not by this program, and passing an external exam is not guaranteed.

What laptop do students need?

Recommended laptop specifications (recommendations, not entry requirements): CPU: Intel Core i5 / Ryzen 5 (recent generation); RAM: 16 GB; Storage: 512 GB NVMe SSD; GPU: Integrated graphics is sufficient; dedicated GPU not required; Display: 14–16" Full HD IPS.

What kinds of roles does this program prepare students for?

The curriculum lists entry-level roles such as Junior Software Developer, Junior Software Engineer, Junior Frontend Developer, Junior Backend Developer. Fit depends on the student's portfolio and on each employer's requirements.
