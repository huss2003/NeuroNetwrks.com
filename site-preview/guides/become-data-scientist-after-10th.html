In short

  • Yes, you can start after Class 10. Python, SQL and statistics are taught from zero, so no coding background is needed.
  • Plan for about three years of skill building: data and statistics, then machine learning, then deep learning and generative AI.
  • Maths matters more here than in most tech roles. Keep Mathematics in Class 11 and 12 if you possibly can, because modelling rests on statistics and algebra.

A data scientist uses data to answer hard questions and make predictions. They clean messy data, test ideas with statistics, build machine learning models, and explain what the results mean for a business. The role sits between maths, code and clear communication.

Can you start on the path to a data scientist right after Class 10?

Yes. A student can start learning data science right after Class 10, because the first months teach computing, Python and basic statistics from the beginning, with no prior coding expected.

Your Class 11 and 12 stream matters a lot for this role, because data science leans on maths. Here is how each path looks.

Which skills does a data scientist need?

A data scientist needs statistics, Python with NumPy and Pandas, SQL, data cleaning, machine learning, model evaluation, some data engineering, deep learning basics and the ability to explain results to people who are not technical.

Nasscom's Strategic Review 2026 describes AI moving from an optional extra to core infrastructure in India's tech industry. That is why this roadmap does not stop at analysis, and carries data science through to machine learning in production and generative AI.

What will you build on the way?

You build one project every month, so by the end you hold 36 projects, moving from statistics reports to working machine learning models, an ML API and a final data science capstone.

These are real projects from the Data Science & AI roadmap, in the order a student meets them:

  1. Statistical Investigation. Your first real question answered with evidence, not guesses.
  2. Regression & Classification Project. The two model types most data science work starts from.
  3. Model Evaluation Portfolio. Shows you can tell a good model from one that only looks good.
  4. Forecasting Case Study. Predicting the future from past data, a common business ask.
  5. Production ML API. Your model answering requests from another app, not just sitting in a notebook.
  6. NLP Project. A model that reads and sorts text such as reviews or messages.
  7. Deep Learning Project. Neural networks on a problem that simple models cannot handle well.
  8. Final Data Science & AI Capstone. One complete project from raw data to a working, explained result.

A parent can open the GitHub page at any time and see the work. That is often more convincing than a marksheet.

Which certificates help a future data scientist?

Certificates such as IBM Data Science and Microsoft AI-300 can show an employer specific skills, but each one is awarded by its own body after its own assessment, and a portfolio of real models still counts most.

The Data Science & AI program prepares students for these 6. Each is awarded by its own certifying body after its own exam, and passing is not guaranteed.

  • Microsoft Certified: Azure Data Fundamentals (DP-900).
  • HackerRank Python & SQL Certificates.
  • Google Data Analytics Professional Certificate.
  • IBM Data Science Professional Certificate. A 12-course series on Coursera covering Python, SQL, data visualisation and machine learning. IBM says no prior experience is required, with high school maths helpful.
  • Microsoft AI-300 (Machine Learning Operations Engineer Associate). An intermediate exam on running machine learning and generative AI systems on Azure. Microsoft expects a data science background with Python, so it sits in year 2 after the basics.
  • IBM Data Engineering Professional Certificate.

The roadmap also prepares for Microsoft DP-900 and the Google Data Analytics certificate in year 1, which suit the analysis side of the role.

Who should not choose this path?

This path is not for you if you dislike maths, want instant results, or would rather build apps than question data, since much of a data scientist's day is checking whether an answer is really true.

  • You avoid maths whenever you can. Statistics runs through all three years. You do not need to be a topper, but you must be willing to practise.
  • You want quick, visible results. Most models fail at first. Patience with messy data is part of the work.
  • You would rather build apps and websites. Look at the Software Development program instead.
  • You expect a guaranteed job. No honest course can promise a job, salary or exam pass, and this one does not.
  • You have only a phone or an old laptop. Deep learning in year 3 needs a capable laptop. Check the recommended specification first.

What should parents ask before choosing a course?

Parents should ask five things of any course: can I see the full curriculum, what will my child build, how is learning checked, who answers questions, and what exactly is promised.

  1. Can I see the whole curriculum, month by month? A good course shows every module and its hours before you pay.
  2. What will my child build, and where will I see it? Ask for project names and whether work goes on GitHub.
  3. How is learning checked, and how often? Regular exams and practicals show progress early, not only at the end.
  4. Who answers questions, and how quickly? Ask how doubts are handled between classes.
  5. What is promised, and what is not? Get the certificate, timings and fees in writing. Be careful of anyone who guarantees a job or salary.

What can a data scientist earn in India?

Indicative ranges for data science roles in India are about ₹4 to 8 lakh a year for freshers, ₹10 to 22 lakh at 3 to 5 years, and ₹25 to 50 lakh or more for senior people.

Frequently asked questions

How many years does it take to become a data scientist after 10th?

Plan for about three years of steady learning to build job-ready data science skills, such as the 3-year, 624-hour Data Science & AI program. Many employers also expect a degree, so the full route usually runs through Class 11 and 12 and a degree, with skills built alongside.

Can I become a data scientist without maths?

It is very hard. Data science rests on statistics, probability and algebra, and the program teaches statistics in two full modules. Without Mathematics in Class 11 and 12, analyst roles stay open, but you would need to relearn school maths for modelling.

What is the difference between a data scientist and a data analyst?

A data analyst mainly explains what happened, using SQL, statistics and dashboards. A data scientist also builds models that predict what will happen. In this roadmap, year 1 covers the analyst skills and years 2 and 3 add the data scientist skills.

Do I need to learn deep learning to become a data scientist?

Not for every job, since many data scientists work mostly with statistics and classic machine learning. The roadmap still covers deep learning, NLP and computer vision in year 3, because more data science work now involves text and images.

Does the program guarantee a data science job?

No. The program aims at job readiness through skills, monthly projects and a GitHub portfolio, but it does not guarantee a job, internship, salary or exam pass.
