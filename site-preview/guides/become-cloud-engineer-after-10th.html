In short

  • Cloud engineers still need to code. Deployment, automation and cloud services all assume you can build software.
  • This roadmap takes a developer's route into cloud: AZ-900 readiness, AWS developer skills, CI/CD, DevOps and cloud-native design.
  • Cloud certificates come in levels. Fundamentals early, associate-level only after real hands-on practice.

A cloud engineer builds, deploys and runs software on platforms such as AWS and Azure instead of on a company's own servers. They automate how code is tested and released, keep services running when traffic jumps, and watch cost, security and reliability. It sits between software development and operations.

Can you start on the path to a cloud engineer right after Class 10?

Yes, but not with cloud first: after Class 10 you start with programming, Linux-style computer basics and web apps, because cloud work means deploying and automating real software, and you need software to deploy.

Cloud roles often ask for a computing degree, so your stream should keep a technical degree open. Here are the options.

Cloud is less visible than apps or websites, so it can sound abstract at 15. A simple test: if you enjoy making things run automatically and reliably, more than designing how they look, cloud work may suit you. Interested in protecting cloud systems? See Cybersecurity.

What is the year-by-year roadmap to become a cloud engineer?

Which skills does a cloud engineer need?

A cloud engineer needs programming, Linux and Git, cloud basics across compute, networking and storage, hands-on AWS and Azure services, Docker containers, CI/CD and DevOps automation, cloud-native design, and reliability, performance and security habits.

Nasscom's Strategic Review 2026 describes cloud-native architecture as widespread across India's $315 billion tech industry. That is why this roadmap treats cloud as a thread through all three years, not a single module at the end.

What will you build on the way?

You build a project every month, and for cloud the key ones are an AWS-deployed application, a containerised CI/CD pipeline, a distributed systems design, a cloud-native application and an AWS production engineering lab.

These are real projects from the Software Development roadmap, in the order a student meets them:

  1. AWS-Deployed Application. Your first app running on AWS, reachable by anyone with the link.
  2. Containerized CI/CD Project. Code that builds, tests and deploys itself, the heart of DevOps work.
  3. System Design Casebook I. Practice planning systems before building them, a daily cloud skill.
  4. Distributed Systems Architecture Project. Many services working together, as most cloud systems do.
  5. Cloud-Native Application. An app designed to scale and recover on the cloud from day one.
  6. Performance Engineering Report. Measures speed and limits, the evidence cloud teams act on.
  7. Secure Software Development Project. Builds security into the system rather than adding it at the end.
  8. AWS Production Engineering Lab. Production-style practice on AWS, close to real cloud operations.

A parent can open the GitHub page at any time and see the work. That is often more convincing than a marksheet.

Which certificates help a future cloud engineer?

Cloud is one of the few areas where vendor certificates are widely used to show skill; this roadmap prepares for Azure Fundamentals early and AWS Developer Associate later, each awarded by Microsoft or AWS after their own exam.

The Software Development program prepares students for these 6. Each is awarded by its own certifying body after its own exam, and passing is not guaranteed.

  • Microsoft Certified: Azure Fundamentals (AZ-900). A beginner-level, 45-minute exam on cloud concepts, Azure architecture and services, and Azure management and governance.
  • Oracle Certified Foundations Associate (Java).
  • HackerRank Skills Certification (SQL / Problem Solving).
  • Meta Front-End Developer Professional Certificate.
  • Oracle Certified Professional, Java SE (OCPJP).
  • AWS Certified Developer – Associate. Validates developing, testing, deploying and debugging cloud-based applications on AWS, including CI/CD workflows. It has 65 questions in 130 minutes, and AWS recommends one or more years of hands-on experience first.

A timing note: AWS says registration for the updated Developer – Associate exam (DVA-C03) opens on 27 October 2026, and the last day for the current DVA-C02 is 30 November 2026. AWS suggests people with no IT experience consider AWS Certified Cloud Practitioner first; it is not part of this roadmap.

Who should not choose this path?

Cloud engineering is not for you if you want to avoid coding, dislike careful, step-by-step setup work, or expect a certificate alone to lead to a job, and this program guarantees no job either.

  • You want cloud without coding. This route treats cloud as a developer skill. You will write and deploy software throughout.
  • Careful setup work bores you. Small mistakes in settings can take a service down. Patience and checklists matter.
  • You think a certificate is enough. Associate-level exams expect real hands-on practice, and employers look for projects too.
  • You want to focus mainly on security. If defending systems interests you more than building them, look at Cybersecurity, which includes cloud security modules.
  • You want a guarantee. No job, salary or exam pass is promised.

What should parents ask before choosing a course?

Parents should ask five things of any course: can I see the full curriculum, what will my child build, how is learning checked, who answers questions, and what exactly is promised.

  1. Can I see the whole curriculum, month by month? A good course shows every module and its hours before you pay.
  2. What will my child build, and where will I see it? Ask for project names and whether work goes on GitHub.
  3. How is learning checked, and how often? Regular exams and practicals show progress early, not only at the end.
  4. Who answers questions, and how quickly? Ask how doubts are handled between classes.
  5. What is promised, and what is not? Get the certificate, timings and fees in writing. Be careful of anyone who guarantees a job or salary.

Frequently asked questions

How many years does it take to become a cloud engineer after 10th?

Plan for about three years of steady work, such as this 624-hour roadmap, because you first learn to build software and then to deploy and run it on the cloud. Many cloud roles also ask for a degree.

Can I become a cloud engineer without maths?

Yes, much cloud work relies on logic, systems thinking and careful setup rather than advanced maths. But B.Tech through JEE Main needs Physics and Mathematics in Class 12, and it is a common route into cloud roles.

Should I learn AWS or Azure first?

This roadmap starts with Azure Fundamentals readiness in year 1 for broad cloud concepts, then spends years 2 and 3 on AWS developer skills. The concepts carry across both.

Is cloud engineering the same as DevOps?

They overlap. DevOps focuses on how code is built, tested and released, while cloud engineering covers the platforms it runs on. This roadmap teaches CI/CD and DevOps inside its cloud thread.

Can I take AZ-900 while still in school?

Microsoft lists AZ-900 as a beginner-level exam. This roadmap prepares for it at the end of year 1. Passing is not guaranteed, and the exam is awarded by Microsoft, not by this program.
