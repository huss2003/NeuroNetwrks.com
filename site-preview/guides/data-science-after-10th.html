Data science after 10th:skills, path and projects

Data science teaches a student to ask good questions of data and answer them with code. This is what the path looks like from Class 10.

In short

  • Data science after Class 10 starts with Python, SQL and statistics, then analytics and dashboards, then machine learning.
  • The Data Science & AI program is 3 years and 624 hours, and absolute beginners are welcome.
  • Students finish with a portfolio including dashboards, data pipelines, an ML API, a RAG application and a capstone.

What is data science, in simple words?

Data science is using data to answer questions and make decisions. A data scientist collects and cleans data, explores it with statistics and charts, builds models that predict or group things, and explains the results clearly. It combines programming, mathematics and communication, which is why it suits students who like both numbers and explaining ideas.

What does the 3-year course cover?

The Data Science & AI program, one module per month:

  1. Year 1 (208 hours): Computer, Data & Python Foundations, Python Programming for Data, SQL Fundamentals, Statistics I, Statistics II, NumPy & Pandas, Data Visualization, Exploratory Data Analysis, Business Analytics, Dashboarding, Google Data Analytics Preparation, Year-1 Capstone & DP-900.
  2. Year 2 (208 hours): Machine Learning Foundations, Feature Engineering & Evaluation, Classification & Ensembles, Unsupervised Learning, Time Series, Data Engineering Foundations, Python Data Engineering, Azure ML & DP-100 Preparation, ML Deployment & MLOps, IBM Data Science Integration, IBM Data Engineering Integration, Year-2 Integrated Capstone.
  3. Year 3 (208 hours): Advanced Machine Learning, Deep Learning, NLP, Computer Vision, Generative AI & RAG, Data Engineering at Scale, Advanced Analytics & Experimentation, Responsible AI, MLOps, Real-World Data Project, GitHub, Portfolio & Interviews, Final Data Science & AI Capstone.

Data science or AI/ML engineering?

Both use Python and machine learning. Data science leans towards analysis, statistics, dashboards and data engineering. AI/ML Engineering leans towards building and deploying AI systems: deep learning, transformers, agents and MLOps. Students who enjoy explaining findings often prefer data science; those who enjoy building software with AI often prefer AI/ML.

What do students build?

Examples include data notebook + python repository, data cleaning notebook portfolio, google-style analytics capstone, segmentation/anomaly project, production ml api, deep learning project, product experimentation case and final data science & ai capstone.

Which certifications does it prepare for?

Microsoft Certified: Azure Data Fundamentals (DP-900), HackerRank SQL / Python Certificate, Google Data Analytics Professional Certificate, IBM Data Science Professional Certificate, Microsoft Certified: Azure Data Scientist Associate (DP-100) and IBM Data Engineering Professional Certificate. No program guarantees a job, internship, salary or exam pass. Certification exams are run and awarded by the certifying organisations.

What can you earn in India?

Entry-level roles in this field typically pay ₹4–8 LPA a year in India, rising to ₹10–22 LPA with 3–5 years' experience and ₹25–50+ LPA at senior level. These are indicative market ranges, not guarantees.

Frequently asked questions

Can a 10th pass student learn data science?
Yes. The program welcomes absolute beginners and starts with computer, data and Python foundations before SQL and statistics.
Do I need to be good at maths for data science?
Comfort with school mathematics helps. Statistics is taught inside the program in two modules, Statistics I and II, before machine learning.
Which tools are used?
Python, SQL, Git, GitHub, Linux, NumPy, Pandas, Jupyter and Azure.
