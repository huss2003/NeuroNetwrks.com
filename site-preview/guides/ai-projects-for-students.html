AI projects for students:from image classifier to AI agent

The best way to learn AI is to build with it. These are projects from the AI/ML Engineering roadmap, in the order students meet them.

In short

  • Students build one project every month across 36 months of the AI/ML Engineering program.
  • Three flagship examples: an image classification app (Year 2), a document RAG assistant and AgentFlow AI, a tool-using agent (Year 3).
  • Beginners start smaller: Python exercises, data cleaning and a regression model in Year 1.

Why do projects matter when learning AI?

Projects turn ideas into skills. Training a model, testing it on new data and building a simple interface teaches more than reading about it, and every finished project becomes portfolio evidence. That is why each monthly module in the three-year programs ends with a project, followed by a one-hour exam.

Which AI projects come first?

Year 1 of AI/ML Engineering builds foundations: ai concept map + python mini exercises, cli utility collection, python data-processing toolkit, math-for-ml notebook, statistical experiment notebook, messy-dataset cleaning project, ai productivity + evaluation project, house-price/regression project, azure ai mini solution, customer-risk classifier, customer segmentation project and year-1 production-style ml project.

Image classification application

In Year 2, students prepare an image dataset, train or load a model, evaluate its predictions and build a simple web interface. See the image classification project.

Document RAG assistant

In Year 3, students build an assistant that answers questions from documents using retrieval-augmented generation, with answers that cite their sources. See the document RAG assistant.

AgentFlow AI: a tool-using agent

Also in Year 3, students build an AI agent that plans tasks, calls tools such as web search, code execution and file operations, and verifies its results safely. See AgentFlow AI.

Can beginners do AI projects?

Yes, at the right scale. The 1-year AI Foundation course includes practical ai audit, responsible ai workshop, debugging and programming challenge, cleaned-csv data mini-project on github, ml mini-project and practical assessment, practical multimodal ai application, small generative ai application and prompt evaluation benchmark project.

Frequently asked questions

What is a good first AI project for a student?
A small machine learning project on a clean CSV dataset, such as predicting a number or a category, is a good start. AI Foundation includes an ML mini-project of this kind.
Do students need a GPU for these projects?
Not at first. Integrated graphics are enough for basic ML. An NVIDIA RTX 4060 8 GB or better is recommended for the full AI/ML roadmap, mainly for deep learning.
Where can I see all projects?
Every project, month by month, is on the curriculum page and the projects page.
