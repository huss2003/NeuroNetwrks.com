Technical architecture

How the system works.

A simple architecture that combines document processing, vector search and a large language model.

  1. DocumentsPDFs, docs, text files
  2. Text extractionExtract and clean text content
  3. Chunking & embeddingsSplit into passages and create embeddings
  4. Vector indexStore embeddings in a vector database
  5. RetrieverFind relevant passages
  6. LLM responseGenerate grounded answer
  7. Source citationsLink to original documents
