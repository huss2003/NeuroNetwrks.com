From data to deployment

How it works

Follow a clear, end-to-end process to build the image classification application, from preparing data to deploying a simple web interface.

  1. 01Prepare datasetUse a labelled dataset such as ImageNet, or a smaller dataset provided in the program.
  2. 02Train or load modelTrain a model or use a pre-trained model with transfer learning.
  3. 03Evaluate predictionsTest the model on unseen images and review the results.
  4. 04Deploy interfaceBuild a simple web app with Streamlit to try it yourself.
