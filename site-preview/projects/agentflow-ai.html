Step by step

How the agent
works.

The agent follows a clear process from understanding your request to delivering a final result, using the right tools at each step.

  1. 01Interpret requestUnderstand what you are asking for.
  2. 02PlanBreak the task into smaller steps.
  3. 03Choose toolSelect the most appropriate tool for each step.
  4. 04ExecuteRun the tool and observe the results.
  5. 05Verify resultCheck the output and handle errors if needed.
  6. 06RespondProvide the final answer with references or files.

Safety by design

Safety and
control.

Learn how to build agents that are useful, reliable and safe, with clear permissions and human oversight where needed.

  • Permission controlLimit what tools can do and which resources they can access.
  • Approval for sensitive actionsRequire confirmation before critical operations such as file changes.
  • Execution logsKeep a record of tool calls, inputs and outputs for transparency.
  • Result validationCheck and verify outputs to reduce errors and hallucinations.
