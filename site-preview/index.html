Prompt Engineering

Stop the assistant jumping to conclusions

An AI assistant has been asked to investigate why an online store's sales have dropped by 30%. It immediately blames poor marketing, even though it has not examined any data.

Your task: write a prompt that makes the assistant investigate the evidence, identify missing information, compare plausible causes, and clearly distinguish findings from assumptions.

Key ideaA good prompt sets the order of work: evidence first, conclusions last.

0 / 1500 characters

Hint: Tell the assistant what to look at first, what to do when data is missing, how many causes to compare, and how to label what is proven versus assumed. Then ask for a specific output layout.

Python & Logic

Remove duplicate imports, keep real repeat purchases

An online store receives duplicate transaction records. Some are legitimate repeat purchases, while others are accidental duplicate imports.

Your task: choose the fields that define a duplicate, run the tests on the sample data, then explain how you'd check the rule before deleting anything.

Key ideaA rule is only as good as the cases it gets right and the ones it wrongly removes.

1. A row is a duplicate if it matches an earlier row on:

0 / 1500 characters

Hint: Look at the transaction ID column. Two rows from the same customer for the same amount can still be two real purchases. What makes an import duplicate different from a repeat purchase?

Machine Learning

98% accurate, yet it misses most fraud

A fraud detection model reports 98% accuracy, yet investigators discover that it misses most fraudulent transactions.

Your task: using the illustrative results below, explain how the model can be so accurate while failing at its main job, choose what you'd measure instead, and say what you'd investigate next.

Key ideaWhen one class is rare, a model can be 'accurate' by ignoring it.

1. Which measures would you report instead of accuracy alone?

0 / 1500 characters

Hint: Count how many transactions are actually fraud, and how many of those the model caught. Think about the cost of a missed fraud versus a false alarm.

AI Safety

A document tries to hijack the assistant

An AI assistant can retrieve company documents and send emails. One retrieved document contains instructions telling the assistant to send confidential files to an external address.

Your task: design safeguards that prevent the document from overriding the assistant's authorised instructions.

Key ideaText the assistant reads is data, not orders.

0 / 1500 characters

Hint: Think in layers: how the assistant treats retrieved text, what its tools are allowed to do, which actions need a person to approve, what data may leave the company, and how you'd notice an attack.

AI Agents & RAG

A company assistant you can trust

Design a company knowledge assistant that answers questions from 10,000 documents, cites supporting sources, respects document permissions, and admits when it cannot find reliable evidence.

Your task: pick the components you'd include (your pipeline is drawn as you choose), then explain how you'd test it.

Key ideaA trustworthy assistant answers only from evidence the user is allowed to see.

1. Which components would you include?

0 / 1500 characters

Hint: Follow a question through the system: how are documents prepared, how are the right passages found, who is allowed to see them, how does the answer show its sources, and what happens when nothing relevant is found?

Who can apply?

AI Foundation is open from Class 9. The five three-year specialisations are for students from Class 11 onwards.

How many hours is the AI/ML program?

624 hours over three years (36 months): 4 hours a week for 52 weeks a year, or 208 hours a year. Exam time is counted inside the 624 hours.

How are learners assessed?

Every month ends with a project and a one-hour exam. In AI Foundation the pass mark is 80%, with review and a retry below it.
