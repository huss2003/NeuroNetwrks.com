## Final step: send the profile links to Claude

**Send the profile links to Claude so they are added to the website's sameAs schema.**

Copy the full link of each profile (for example `https://www.linkedin.com/company/neuronetworksaied`) from the checklist above and paste them all into one message to Claude, saying:

> "Here are the NeuroNetworks AI Ed profile links. Please add them to the website's sameAs schema and the footer."

`sameAs` is a hidden label in the website code that tells Google and AI search tools "these profiles belong to this organisation". It is one of the fastest ways for a new brand to be recognised as a real entity. Do the same later for any listing in `listings.md` that gives you a public profile page (Crunchbase, GitHub, Google Business Profile).
