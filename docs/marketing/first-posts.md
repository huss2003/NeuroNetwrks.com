## How to use this file

1. Copy the **hook**, **body** and **call to action** into the post, in that order. Add the hashtags at the end.
2. **LinkedIn:** paste the link as it is. For tracking, add `?utm_source=linkedin&utm_medium=social&utm_campaign=launch` to the end of the link.
3. **Instagram:** links in captions cannot be clicked. Before posting, change the link in your bio to the post's URL (with `?utm_source=instagram&utm_medium=social&utm_campaign=launch`), and keep "Link in bio" in the caption.
4. **Visuals:** start from `docs/marketing/assets/post-template.png` (1080×1080). Use real screenshots (code, notebooks, wireframes) where suggested. No stock photos of brains, robots or AI-generated faces. No emoji as icons.
5. Do not add claims about results, jobs or student numbers, even in replies to comments. If someone asks about fees, reply: "Fees are shared on enquiry. Please write to Hussain@neuronetwrks.com."

## Post 5 · LinkedIn · Career options after 10th (for parents)

**Hook:**
If your child likes computers but doesn't know which direction to take after Class 10, start with what each path asks of them day to day.

**Body:**
AI/ML Engineering suits a student who enjoys maths and patterns. They will use Python, NumPy, PyTorch and TensorFlow.

Software Development suits a student who likes building things that work. They start with programming logic and Java, then JavaScript, React and databases.

Data Science & AI suits a student who asks "why?" about numbers. Python, SQL, statistics and dashboards come first.

Product & UX / AI Design suits a student who notices when an app is confusing. User research, wireframes and prototypes come first.

Cybersecurity suits a student who is careful and curious about how systems break. Networking, Linux and security monitoring come first, with ethical hacking only in authorised labs.

Each three-year curriculum names entry-level roles it is designed around. These are directions, not promises: fit depends on the student's portfolio and each employer.

## Post 11 · LinkedIn · AI vs software vs data science (for parents)

**Hook:**
AI, software or data science? Three paths that sound similar but feel different from the first month.

**Body:**
AI/ML Engineering starts with Python and maths for ML, then machine learning, deep learning, generative AI and MLOps. Tools: Python, NumPy, Pandas, scikit-learn, PyTorch, TensorFlow.

Software Development starts with programming logic and Java, then web, React, databases, Spring Boot and cloud. Tools: Java, JavaScript, TypeScript, React, SQL, Docker.

Data Science & AI starts with Python, SQL and statistics, then analytics, dashboards, machine learning and data engineering. Tools: Python, SQL, NumPy, Pandas, Jupyter.

One practical difference for parents: the laptop. The software curriculum works with integrated graphics and 16 GB RAM. The data science curriculum lists 32 GB RAM and an NVIDIA RTX 4060/5060 GPU. AI/ML lists 16 GB RAM minimum, with an RTX 4060 recommended for the full roadmap.

All three are 3 years, 624 hours, 4 hours a week.

**Call to action:**
Read the full parent's guide: https://neuronetwrks.com/guides/ai-vs-software-vs-data-science

**Hashtags:** #ParentsGuide #AfterClass10 #CareerAfter10th #DataScience #SoftwareDevelopment
