**624 Hours • 36 Months • 4 Hours/Week • Absolute Beginner → Professional / Job-Ready**

**Program purpose.** A three-year specialization for a student entering after Class 10 who chooses Product & UX / AI Design. The path begins with visual and UX fundamentals, progresses through product thinking and project management, and ends with AI-assisted product design, research, systems, prototyping and a professional portfolio.

- Design fundamentals: composition, hierarchy, typography, spacing, grids and visual consistency.

- User experience fundamentals and human-centered design.

- User research: interviews, surveys, observation, personas and journey mapping.

- Problem framing, user needs, jobs-to-be-done concepts and opportunity discovery.

- Information architecture, navigation and content organization.

- Wireframing from low to high fidelity.

- UI design for web and mobile products.

- Interaction design, states, flows, feedback and usability.

- Clickable prototypes and design handoff.

- Usability testing and evidence-based iteration.

- Design systems, components, tokens and reusable patterns.

- Accessibility and inclusive design principles.

- Product requirements, prioritization and roadmaps.

- Agile/Scrum concepts and product delivery.

- AI product discovery and AI-assisted design workflows.

- Prompting and responsible use of generative AI in design work.

- AI UX patterns: uncertainty, citations, feedback, human oversight and error recovery.

- AI product evaluation and user trust considerations.

- Design documentation and developer handoff.

- GitHub-based portfolio documentation and professional case studies.

# 7. GitHub + Portfolio Standard

- 6–10 flagship case studies/projects by graduation.

- Each case study should show the problem, research evidence, user needs, design decisions, iterations, prototype and outcome.

- Include research artifacts rather than only polished screens.

- Show before/after reasoning and explain why major design decisions were made.

- Include responsive web, mobile, dashboard and AI-product examples.

- Include at least one accessibility-focused project and one complex enterprise workflow.

- Include AI-specific UX patterns: uncertainty, generated content, citations, correction, feedback and human oversight.

- Use GitHub for structured project documentation and version history where appropriate.

- Final portfolio should demonstrate progression from basic visual design to advanced product and AI design.
