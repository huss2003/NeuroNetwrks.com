**624 Hours • 36 Months • 4 Hours/Week • Absolute Beginner → Professional / Job-Ready**

**Program purpose.** A three-year specialization for a student entering after Class 10. The student has a basic understanding of mathematics and Computers. The student chooses AI/ML Engineering as one specialization and progresses from computer and Python fundamentals to machine learning, deep learning, generative AI, production AI systems, MLOps and portfolio-ready projects.

# 3. Skills Gained by the End

- Computer, operating-system, command-line and programming fundamentals.

- Python programming for AI/ML, debugging, virtual environments, packages and clean code.

- NumPy, Pandas, data cleaning, visualization and dataset preparation.

- Probability, statistics, linear algebra and calculus concepts needed for ML.

- Supervised and unsupervised learning; regression, classification, clustering and dimensionality reduction.

- Feature engineering, model selection, cross-validation, metrics, error analysis and experimentation.

- Scikit-learn and production-oriented ML workflows.

- Deep learning with neural networks, CNNs and sequence models; practical PyTorch/TensorFlow exposure.

- NLP, embeddings, transformers and modern language-model concepts.

- Computer vision fundamentals and practical image models.

- Generative AI, LLM applications, prompting, embeddings, vector search and RAG.

- Fine-tuning concepts, PEFT/LoRA concepts, model evaluation and safety.

- AI agents and tool-using workflows, with emphasis on evaluation and reliability.

- Model serving, REST APIs, containers, cloud AI services and basic GPU concepts.

- MLOps fundamentals: experiment tracking, model versioning, pipelines, monitoring and deployment.

- Responsible AI: privacy, bias, security, explainability, hallucination control and human oversight.

- Git/GitHub, documentation, reproducible projects and a professional AI/ML portfolio.

# 7. GitHub + Portfolio Standard

- Minimum 6–10 flagship repositories by graduation, plus smaller exercises.

- Every flagship repository: problem statement, architecture, setup instructions, dataset/source notes, methodology, evaluation, limitations and demo evidence.

- Use Git branches, meaningful commits, issues and project documentation.

- Include notebooks where useful, but convert important work into reproducible scripts/services.

- Show both ML metrics and real-world engineering metrics such as latency, reliability and cost where relevant.

- Include at least one classical ML project, one deep-learning project, one NLP/CV project, one GenAI/RAG project, one MLOps project and one end-to-end production-style AI system.

- Final GitHub profile should make the student's progression visible from beginner work to professional-level systems.

# 11. Final Job-Readiness Standard & Capabilities

- Can independently take a problem from requirements → data → model/LLM choice → implementation → evaluation → deployment → documentation.

- Can explain why a model was selected and identify its limitations.

- Can build and debug Python-based AI/ML systems.

- Can work with classical ML, deep learning and modern GenAI workflows.

- Can build RAG and tool-using AI applications and evaluate their quality.

- Understands production concerns: APIs, containers, monitoring, versioning, security and cost.

- Has a GitHub profile containing substantial, reproducible projects.

- Has a portfolio demonstrating progression and real-world engineering ability.

- Can pursue relevant junior AI/ML, applied AI, GenAI, ML, data-science or MLOps opportunities, subject to employer education/experience requirements.

**13. Important Program Notes**

- 4 hours/week is the total program allocation, including practical work and the monthly 1-hour exam.

- Every month contains a major assessment; students should not advance by memorization alone.

- The roadmap deliberately starts with programming, math and data fundamentals before advanced AI topics.

- External certification costs are approximate and can change. Confirm current pricing, exam codes and eligibility before purchase.

- The supplied certification roadmap states that 'no experience required' means no mandatory work experience, not that every employer will waive education or experience requirements.

- Completing this curriculum does not automatically grant any external certification; the student must complete the provider's required course/exam process.
